# RallyGame (web build)

Play: https://shouryap4132.github.io/rallygame-play/

Built files only. Works in Chrome or Edge on a computer, and on phones/tablets with on-screen touch controls.
Controls: W/S throttle/brake, A/D steer, Space handbrake, R reset, C camera, drag mouse to look around, F1 telemetry, F2 graphics, L lights.

Touch: left thumb joystick (up = gas, down = brake, sideways = steer), HANDBRAKE bottom-right, CAM and RESET top-right, drag elsewhere to look around.
